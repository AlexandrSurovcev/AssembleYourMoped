# MopedBuilder 🛠️

3D-симулятор сборки мопеда на Unity, вдохновлённый My Summer Car.

## О проекте
Игрок получает разобранный мопед и должен собрать его из отдельных 
деталей: двигатель, колёса, рама, карбюратор, проводка и т.д. 
Каждая деталь имеет физику, точки крепления и состояние (износ).

## Реализованные механики
- Система крепления деталей (болты, точки соединения)
- Физика деталей и взаимодействие через Rigidbody
- Инвентарь и перетаскивание объектов
- Состояние деталей (износ, поломка)
- UI: подсказки, чек-лист сборки
- Сохранение прогресса

## Технологии
- Unity 2022 LTS (или твоя версия)
- C#
- [URP / HDRP / Built-in] Render Pipeline
- [DOTween / Cinemachine / другие ассеты, если есть]

## Управление
| Действие | Клавиша |
|----------|---------|
| Движение | WASD |
| Взаимодействие | E |
| Инвентарь | Tab |
| Поворот детали | ЛКМ + колесо |

## Как запустить
1. Клонировать репозиторий
2. Открыть проект в Unity [версия]
3. Открыть сцену `Assets/Scenes/Garage.unity`
4. Нажать Play
